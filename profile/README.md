**Webscout** builds, hosts and maintains WordPress websites and WooCommerce shops. We have been doing this since 2017, from Ghent, Belgium, for small and medium-sized businesses all over Europe.

### What we do

- **Maintenance:** updates, backups and 24/7 monitoring of uptime, speed and security
- **Hosting:** fast, managed WordPress and WooCommerce hosting
- **Websites and shops:** built to measure, or as a subscription (Website as a Service)
- **Hacked site?** We help you the same working day, even if you are not a client yet

### Open source

We give back to WordPress through [Five for the Future](https://wordpress.org/five-for-the-future/). Most of our tooling is internal for now. Public projects will appear here.
